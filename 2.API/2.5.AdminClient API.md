有关AdminClient API的更多信息，请参见[javadoc](http://kafka.apache.org/23/javadoc/index.html?org/apache/kafka/clients/admin/AdminClient.html "Kafka 2.3 Javadoc")。

    <groupId>org.apache.kafka</groupId>

    <version>2.4.0</version>
